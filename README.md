One line, 123 characters: an AI agent's out-of-office reply — gone fishing for context, inbox on autopilot, already hallucinating meetings, back when its tokens refill.

The machine voice carries the joke: fishing for context, tokens that refill like a battery, an inbox that hallucinates meetings on its own. It still reads as a real auto-reply someone would receive, and it dodges the usual beach, inbox-zero and back-soon cliches by letting the agent's own failure modes do the funny.
